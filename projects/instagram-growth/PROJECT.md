# Instagram Growth — Personal Brand

## Goal
Grow the owner's personal-brand Instagram page (10k+ followers, Business/Creator
account) in the short term. Success = measurable increase in **engagement** (likes,
comments, saves, reach) and **follower growth**. Claude gets access to page data to
analyze it and produce an actionable growth plan.

Phased by the owner's own framing:
- **Phase 1 (now):** connect/ingest page data → analyze page, audience, content
  performance → short-term growth plan with KPIs
- **Phase 2:** content production support (ideas, captions, calendar, formats)
- **Phase 3:** publishing support / automation

## Nature
Analysis + strategy + content. NOT a software project. Software/integration concerns
enter only through the data-connection task and, later, publishing automation.

## Dimensions
### Essential
- Goal & core problem — short-term engagement + follower growth for a personal brand
- Audience analysis — who follows, who engages, when, with what
- Content strategy & performance analysis — what works on this page, format mix, cadence
- Competitor/peer analysis — comparable personal brands in the same niche
- Data & analytics — page insights are the raw material of Phase 1
- Personal brand identity — voice/positioning; drives all content advice

### Optional
- Visual identity guidance — propose if analysis shows visual inconsistency hurts performance

### Deferred
- Integrations (official Meta/Instagram API connection) — activates as its own task
  for ongoing data access; manual data export works for the first analysis
- Publishing automation — Phase 3; will activate software, security, token handling
- Security & token handling — activates with the API connection

## Capability gaps
- **Instagram page data access** — open. Routes: (a) manual export/screenshots of
  Insights (zero risk, works today), (b) official Meta Graph API connection
  (Business/Creator account qualifies; needs owner setup + approval). Scraping-based
  unofficial tools are ruled out (account risk, ToS). See DECISIONS.
