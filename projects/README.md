# Projects

One folder per project, created by the `new-project` intake — never by hand-copying
another project. Each folder is self-contained and isolated from the others.

Standard memory files in every project (see skill `new-project` for templates):

| File | Role | When it changes |
|---|---|---|
| `PROJECT.md` | Charter: goal, nature, scoped dimensions, project toolbox, open questions | At intake; on scope changes (`evolve`) |
| `STATE.md` | Living status: phase, done, next, blockers | End of every working session |
| `DECISIONS.md` | Append-only log of decisions incl. rejected options/tools | Whenever something significant is decided |

Everything else in a project folder is actual work product (research notes, content
calendars, code, analysis…) organized however serves that project — there is no
imposed structure beyond the three memory files.
