# بات فروشگاه احسان — راهنمای راه‌اندازی

این پوشه کد بات است. روی **Cloudflare Workers + D1** اجرا می‌شود: مجانی، بدون کارت
بانکی، بدون سروری که لازم باشد روشن نگه دارید.

---

## راه‌اندازی (یک‌بار، حدود پانزده دقیقه)

### ۱. حساب Cloudflare
در [dash.cloudflare.com](https://dash.cloudflare.com) یک حساب مجانی بسازید.
کارت بانکی نمی‌خواهد.

### ۲. نصب و ورود
در همین پوشه:

```bash
npm install
npx wrangler login       # مرورگر باز می‌شود، اجازه بدهید
```

### ۳. ساختن دیتابیس

```bash
npx wrangler d1 create ehsan-shop-bot
```

یک `database_id` چاپ می‌کند. آن را در فایل `wrangler.toml` به‌جای
`PASTE_DATABASE_ID_HERE` بگذارید. بعد:

```bash
npx wrangler d1 migrations apply ehsan-shop-bot --remote
```

### ۴. گذاشتن رمزها

```bash
npx wrangler secret put BOT_TOKEN        # توکن بات از BotFather
npx wrangler secret put WEBHOOK_SECRET   # یک رشته‌ی تصادفی که خودتان می‌سازید
```

این‌ها روی Cloudflare ذخیره می‌شوند، **نه داخل این پوشه و نه در گیت**.

### ۵. بالا بردن

```bash
npx wrangler deploy
```

یک آدرس می‌دهد مثل `https://ehsan-shop-bot.<اسم-شما>.workers.dev`.

### ۶. وصل کردن به تلگرام

آدرس بالا و همان `WEBHOOK_SECRET` را در این خط بگذارید و اجرا کنید:

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://<آدرس-ورکر-شما>/" \
  -d "secret_token=<WEBHOOK_SECRET>" \
  -d 'allowed_updates=["message","callback_query","channel_post"]'
```

> `allowed_updates` مهم است: بدون آن تلگرام پست‌های کانال را نمی‌فرستد و بات
> هیچ محصولی نخواهد داشت.

### ۷. مشخص کردن مدیر ⚠️ مهم
در تلگرام به بات پیام بدهید:

```
/setadmin
```

**اولین کسی که این را بزند مدیر می‌شود** و بعد از آن دیگر برای کسی کار نمی‌کند.
پس این را همان اول، قبل از اینکه بات را به کسی بدهید، خودِ احسان بزند.

اگر می‌خواهید ببینید شناسه‌ی عددی یک نفر چند است، `/id` را بزند.

### ۸. اتصال کانال
بات باید در کانال احسان **ادمین** باشد (این کار انجام شده). از این به بعد هر پستی
که احسان در آن کانال بگذارد، خودکار خوانده و ذخیره می‌شود.

**امتحان کنید:** چند محصول در کانال بگذارید، بعد در بات اسم یکی را بنویسید.
باید کارت محصول با عکس و قیمت بیاید.

## کار روزانه‌ی احسان

فقط یک کار: **کانالش را مرتب نگه دارد**، با قالب ثابت:

```
سطر ۱  اسم محصول
سطر ۲  قیمت
سطر ۳  جنس
سطر ۴  تعداد هر بسته
سطر ۵+ توضیحات
```

قالب کامل با نمونه و قواعدش در **[POSTING-GUIDE.md](POSTING-GUIDE.md)** است — آن را به
احسان بده. بقیه‌اش خودکار است.

اگر قیمت چیزی عوض شد، **دوباره پستش کند** — بات همیشه تازه‌ترین پست هر محصول را
ملاک می‌گیرد، حتی اگر قیمت جدید بالاتر باشد.

⚠️ **اگر پستی را از کانال پاک کند، بات نمی‌فهمد.** تلگرام حذف شدن پست را به بات خبر
نمی‌دهد، پس آن محصول همچنان به مشتری‌ها نشان داده می‌شود. برای برداشتنش از
**🗑 حذف یک محصول** استفاده کند: نام محصول را می‌نویسد و بات همه‌ی پست‌های آن را
از حافظه پاک می‌کند.

هر وقت مشتری چیزی جستجو کند که پیدا نشود، احسان یک پیام می‌گیرد و در بخش
**«📥 جستجوهای بی‌نتیجه»** می‌تواند با یک ضربه بگوید این همان فلان کالاست.
کاتالوگ این‌طوری خودش ساخته می‌شود — لازم نیست از اول صدها کالا وارد شود.

## پنل مدیریت

با دکمه‌ی **🛠 مدیریت** باز می‌شود و فقط برای احسان دیده می‌شود.

| بخش | کار |
|---|---|
| ➕ افزودن کالا / اسم‌های دیگر | یک کالا با همه‌ی اسم‌هایی که مشتری‌ها صدایش می‌کنند |
| 📥 جستجوهای بی‌نتیجه | جستجوهای بی‌جواب مشتری‌ها؛ با یک ضربه به کالا وصل می‌شوند |
| 📈 گزارش مشتری‌ها | چه کسانی آمدند، چه استعلام گرفتند، چه سفارشی دادند |
| 📊 سفارش‌ها | آخرین سفارش‌ها و وضعیتشان |
| 🗑 حذف یک محصول | نامش را می‌نویسید و از حافظه‌ی بات برداشته می‌شود |
| 🧹 پاک‌سازی حافظه | پاک کردن همه‌ی محصولات، یا ریست کامل برای تست |

**گزارش مشتری‌ها** سه بازه دارد: ۲۴ ساعت، ۷ روز، ۳۰ روز. در هر بازه نشان می‌دهد چند
مشتری فعال بوده‌اند (و چند نفرشان تازه‌اند)، چند استعلام گرفته شده و چند موردش پیدا
نشده، چند سفارش ثبت شده، و فهرست آخرین استعلام‌ها با نام مشتری و اینکه پیدا شد یا نه.
دکمه‌ی **فهرست مشتری‌ها** هم هر مشتری را با شماره‌اش، تعداد استعلام‌ها، تعداد سفارش‌ها
و آخرین بازدیدش نشان می‌دهد.

بالای این صفحه همیشه نوشته چند پست در حافظه‌ی بات است و آخرین پست مال کی بوده.
اگر آن تاریخ عقب افتاد، یعنی کانال به‌روز نشده و قیمت‌ها دارند قدیمی می‌شوند.

## تغییر تنظیمات

در `src/lib/config.js`:

| تنظیم | یعنی چه | پیش‌فرض |
|---|---|---|
| `FRESHNESS_DAYS` | بعد از چند روز، قیمت دیگر قطعی اعلام نشود | ۷ روز |
| `POST_MAX_AGE_DAYS` | بعد از چند روز، پست کلاً از جستجو خارج شود | ۴۵ روز |
| `MAX_RESULTS` | حداکثر چند گزینه به مشتری نشان داده شود | ۵ |

بعد از هر تغییر: `npx wrangler deploy`

## دو نکته‌ای که باید بدانید

**۱. اولین قیمتی که در پست نوشته شود، همان است که مشتری می‌بیند.** اگر پستی دو قیمت
داشته باشد (تکی و عمده)، اولی برداشته می‌شود — پس قیمت اصلی باید سطر دوم باشد.
اگر هیچ عددی با «تومان» در پست نباشد، بات می‌نویسد «نیاز به استعلام» و سفارش را
همچنان ثبت می‌کند.

**۲. هر کس وارد بات شود، اول باید شماره‌اش را بدهد.** تا شماره ثبت نشود، بات هیچ
بخشی را نشان نمی‌دهد. یک ضربه روی دکمه‌ی تلگرام کافی است و تایپ لازم ندارد. دلیلش این
است که کار احسان تماس گرفتن است — بازدیدکننده‌ی بی‌شماره سرنخی است که نمی‌شود پیگیری کرد.
(خودِ احسان از این قاعده مستثناست.)

**۳. بات فقط یک پیام دارد و همان را عوض می‌کند.** هر مرحله جای مرحله‌ی قبلی را می‌گیرد
تا تاریخچه‌ی چت شلوغ نشود. پیام‌های خودِ مشتری می‌مانند — تلگرام به بات اجازه‌ی حذف
آن‌ها را نمی‌دهد.

**۴. اطلاعات تماس از توضیحات پاک می‌شود.** بات پست را فوروارد نمی‌کند، خودش کارت
جدید می‌سازد و هر آیدی، لینک و شماره‌ی تلفنی را از متن حذف می‌کند. اگر روزی متنی
را از جای دیگری کپی کردید، این محافظ جلوی لو رفتن اطلاعات فروشگاه‌های دیگر را
می‌گیرد.

## آزمایش روی کامپیوتر خودتان (بدون بالا بردن)

```bash
npx wrangler d1 migrations apply ehsan-shop-bot --local
npx wrangler dev --local
```

بعد در ترمینال دیگری می‌توانید یک پیام ساختگی بفرستید و ببینید بات چه جوابی می‌دهد.
