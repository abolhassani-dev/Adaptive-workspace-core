# فضای کاری هوشمند (Adaptive Workspace)

این مخزن، فضای کاری مرکزی شما برای اجرای پروژه‌های مختلف با Claude Code است —
پروژه‌هایی که ممکن است هیچ ربطی به هم نداشته باشند: رشد پیج اینستاگرام، ساخت بات،
تحقیق بازار، طراحی سایت، سیستم حسابداری، تولید محتوا و هر چیز دیگر.

## چطور از آن استفاده کنید

فقط با زبان ساده حرف بزنید. لازم نیست هیچ مفهوم فنی (Agent، Skill، MCP و…) را بدانید.

**شروع پروژه جدید:**

> «می‌خواهم پیج اینستاگرام نیرو موتور را رشد بدهم.»

Claude پروژه را می‌فهمد، فقط سؤال‌های ضروری را می‌پرسد، ماهیت پروژه را تشخیص می‌دهد،
مشخص می‌کند چه حوزه‌هایی لازم است و چه حوزه‌هایی نه، و پوشه پروژه را با حافظه‌اش
می‌سازد و کار را شروع می‌کند.

**ادامه پروژه:**

> «پروژه اینستاگرام را ادامه بدهیم.»

حتی در یک Session کاملاً جدید، Claude وضعیت پروژه را از فایل‌های حافظه همان پروژه
بازیابی می‌کند: چه تصمیم‌هایی گرفته شده، چه چیزهایی رد شده، الان کجای کار هستیم.

**اضافه کردن نیاز جدید:**

> «حالا می‌خواهم انتشار محتوا هم خودکار شود.»

Claude پروژه را از اول شروع نمی‌کند؛ فقط بررسی می‌کند این خواسته چه چیزی اضافه
می‌کند، روی چه چیزهایی اثر دارد، چه ریسک یا هزینه‌ای دارد، و فقط همان تغییرات لازم
را اعمال می‌کند.

## چه رفتاری از این فضای کاری انتظار داشته باشید

- هر پروژه با ماهیت خودش پیش می‌رود — پروژه محتوایی گرفتار مفاهیم نرم‌افزاری نمی‌شود
  و پروژه نرم‌افزاری از تست و امنیت فرار نمی‌کند.
- ابزارهای بیرونی (MCP، Skill و…) فقط وقتی وارد می‌شوند که نیاز واقعی و مشخصی وجود
  داشته باشد، منبع معتبری داشته باشند و از فیلتر ارزیابی (سازنده، نگهداری، امنیت،
  سطح دسترسی، تناسب) عبور کنند. تجربه هر ارزیابی در `toolbox/REGISTRY.md` می‌ماند
  تا پروژه‌های بعدی از آن استفاده کنند.
- در کارهای عادی و برگشت‌پذیر، Claude مستقل عمل می‌کند؛ اما برای موارد حساس
  (اتصال حساب، دسترسی به اطلاعات شخصی، انتشار محتوا، هزینه، حذف داده و…) اول به
  زبان ساده توضیح می‌دهد و از شما تأیید می‌گیرد.
- هیچ رمز، توکن یا اطلاعات حساسی داخل این مخزن ذخیره نمی‌شود.

## ساختار (برای اطلاع — نیازی نیست با آن کار کنید)

```
CLAUDE.md            ← قواعد رفتاری فضای کاری (Claude در هر Session می‌خواند)
.claude/skills/      ← پروتکل‌های شروع پروژه، ادامه، تغییر نیاز، ارزیابی ابزار
toolbox/REGISTRY.md  ← دفترچه تجربه ابزارهای بررسی‌شده (پذیرفته و ردشده)
projects/<نام>/      ← هر پروژه یک پوشه مستقل با حافظه خودش
```

معیار موفقیت این مخزن تعداد فایل‌هایش نیست؛ این است که Claude در پروژه‌های واقعی
دقیق‌تر بفهمد، منظم‌تر تصمیم بگیرد و هیچ‌وقت وضعیت پروژه را گم نکند.
